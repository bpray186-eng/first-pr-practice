# Contributing

Thanks for practicing your first pull request here.

For this exercise, keep the change intentionally small:

1. Fork the repository.
2. Clone or open your fork in VS Code.
3. Create a new branch for your change.
4. Add your name to `Contributors.md` in alphabetical order.
5. Commit the change with a clear message.
6. Push your branch to your fork.
7. Open a pull request back to the original repository's `main` branch.

Please do not edit unrelated files for this exercise. The intended pull request changes only `Contributors.md`.

Before opening the pull request, read the diff. You should see one added line and no removed lines.
